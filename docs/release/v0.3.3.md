# PixelForge Studio v0.3.3

Transform Blender models and animations into palette-constrained pixel-art sprites on Windows, with editable Aseprite layers and PNG/spritesheet exports.

## Highlights

- Static and animated conversion, custom palettes/resolutions, studio lighting and cast shadows.
- Object/collection outlines, selective outlines, edge highlights and saved-render comparison.
- Editable playback FPS and timing exports without regenerating pixels.
- **v0.3.3:** Unified grouping reduces heavy internal borders while retaining editable components. Object Only fit keeps model scale stable as shadows change; shadow-inclusive fit remains available.

## Installation

1. Download `PixelForge-Studio-v0.3.3-win-x64.zip` from the release asset when published.
2. Extract the entire ZIP to a writable folder; launch `Launch.bat` or `PixelForge.Desktop.exe`.
3. Install Blender and Aseprite separately. Standard Steam locations are detected; other paths use `PIXELFORGE_BLENDER` and `PIXELFORGE_ASEPRITE` as described in [the usage guide](../USAGE.md#external-tools).

Windows x64 is required. The .NET desktop runtime is included; no SDK is needed. Verified external versions: Blender 5.3.0 and Aseprite 1.3.18.6. Neither tool is bundled. Existing-frame timing/comparison does not start them.

## Known limitations

Object Only can clip ground shadows instead of shrinking the model. Collection instances and complex external/procedural dependencies are not guaranteed. Save/close Aseprite before applying timing; unsaved external edits cannot be detected. Review sprites at their intended resolution.

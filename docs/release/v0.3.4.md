# PixelForge Studio v0.3.4

A workflow update for the Windows Blender-to-pixel-art desktop application. Rendering and animation-generation algorithms are retained; zero padding removes the validation minimum and permits fully occupied canvases.

- Exact zero padding in slider/numeric modes, with aspect ratios and shared animation framing preserved.
- Clean Windows layout: application/runtime bundled into `PixelForge Studio.exe`, with external `bridge/` scripts and runtime notices.
- Separate remembered directories for each file operation.
- Collapsible color management, HEX copying and removal confirmation.
- Visual/custom outline-color entry with explicit strict-palette approval.
- One remembered transparency/ground preview toggle, clearer dependent settings and bottom-left export actions.
- Temporary render sessions with safe cleanup; favorites and native-editing work can be preserved permanently in the application Library.

Extract the complete `PixelForge-Studio-v0.3.4-win-x64.zip` and run `PixelForge Studio.exe` or `Launch PixelForge.cmd`. Windows x64 is required; the .NET runtime is included. Install Blender/Aseprite separately for generation (verified: Blender 5.3.0, Aseprite 1.3.18.6). Neither tool is bundled.

Renders are temporary until exported/preserved. Changed or unrecognized abandoned files are retained for review. Unsaved external Aseprite changes cannot be detected. Existing saved outputs/settings remain supported. Original source remains MIT licensed.

See [usage](../USAGE.md), [CHANGELOG](../../CHANGELOG.md) and [verification](VERIFICATION.md). This package is locally prepared; no GitHub push or publication is automatic.

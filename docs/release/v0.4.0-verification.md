Actual WPF tests verify live theme resources, persistence after window restart, all seven sections, exact numeric values, conditional visibility, dropdown opening, Blender inspection and generation, dispatcher-driven playback, theme switching during playback, immediate 6/24/7 FPS changes using the same image cache, safe Cancel/Apply timing dialogs, PNG/native/sheet exports and saved-pixel comparison. Timing checks reopen the animation in Aseprite and preserve saved manual edits and every native byte outside duration fields.

The renderer and bridge source files are unchanged. The optional comparison against a separately supplied legacy renderer was skipped because no `PIXELFORGE_LEGACY_CORE` was configured.

## Visual and window review

Real WPF captures cover Dark, Light, expanded settings, animation and comparison. Layout checks exercise 1000×740, 1280×900 and 1600×1080 windows. Integer device-pixel zoom is checked mathematically at 100%, 125%, 150% and 200%. The available interactive display reports 100% DPI; physical fractional-DPI/multi-monitor testing has not been performed.

Minor WPF adaptations retain native window resizing and Windows file dialogs. The sidebar can be widened and independently scrolled when several sections are expanded. Comparison mode selection remains a compact keyboard-accessible dropdown, and precise divider input remains available alongside the draggable handle. All functions remain accessible.

Technical validity is not artistic approval. Unsupported Blender shader/instance/simulation limitations remain as documented in the usage guide.

## Portable executable

The self-contained `artifacts/current/PixelForge Studio.exe` was launched with an isolated profile. Its actual UI reopened the saved mine without Blender, switched Dark to Light, saved PNG and spritesheet PNG/JSON through native dialogs, opened the native document in Aseprite, and dragged the read-only comparison divider from 50% to approximately 78%. Exported frame/sheet file hashes match the saved source PNGs exactly. PNG and sheet dialog directories persisted independently, and Light theme and model settings survived an executable restart. The native document was inspected in Aseprite and closed without edits.

`./Build.ps1 -Check -Publish` succeeded. One restricted-network attempt reported an unavailable NuGet audit endpoint; the final build with normal network access completed without warnings. No third-party application dependencies were added. A clean-machine installation and physical high-DPI display remain untested.

# v0.4.0 — Modern desktop workspace

PixelForge Studio now uses the approved modern WPF workspace, with live Light/Dark themes and mint accents. No rendering algorithms, Blender jobs, palette mapping or native export logic were replaced.

- Seven independently collapsible settings sections live in a resizable sidebar. Their expanded state, theme, numeric input modes and file directories are UI preferences, separate from asset settings.
- Generate Sprite stays at the bottom of the sidebar. PNG, spritesheet and Aseprite actions sit below the preview; ••• contains native/frame export, saved-edit reload and preservation actions.
- Settings load/save and Open asset are in the header. Open asset reuses saved frames without rendering.
- Animation playback, frame stepping, timeline, FPS, duration and Save timing stay together. Timing changes still warn about unsaved external Aseprite edits and preserve saved native artwork.
- Compare uses saved pixels with favorites, frame selection, a draggable divider and side-by-side views. Comparison remains read-only.
- Controls, menus, tooltips and application-owned confirmations follow the selected theme. Windows file dialogs keep their native shell behavior.
- Fit and explicit zoom use whole device pixels, including fractional display scaling; large artwork scrolls rather than being interpolated. Warning text retains a fixed scrollable region.

Build locally with `./Build.ps1 -Check -Publish`. This prepares the Windows executable and does not publish a GitHub release. See [verification](v0.4.0-verification.md) for executed checks and limits.

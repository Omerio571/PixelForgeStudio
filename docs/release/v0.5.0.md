# v0.5.0 — Dynamic lighting and emission

Dynamic Lighting exports neutral palette art, world-space normals and a grayscale material emission mask. All maps share the same canvas, atlas rectangles, animation timing and anchor. Preview them on the same frame, adjust glow tint and strength, and export a version 2 lighting bundle with the editable Aseprite document.

Studio Lighting and Ground Shadows are independent. Studio lighting is a preview for dynamic assets. Explicitly enabling baked ground shadows may conflict with game shadows. Older baked settings keep their original defaults.

The sidebar starts wider, remembers its size and keeps palette buttons together where space permits. Camera Elevation shows degrees.

See the [lighting format and validator](../lighting-assets.md) for authoring, runtime sampling and limitations. Build the local Windows x64 executable and release ZIP with `./Build.ps1 -Check -Package`.

Verification passed 25 base checks, 61 WPF workflow checks, 61 UI polish checks and 43 session and export checks. A pre-update baked reference matched pixel for pixel. Blender and Aseprite integration covered an animated two-strip fixture, Mine10 and a non-emissive reference block at three orientations. Raylib checked atlas pixels against CPU reference calculations with five light directions and three glow states, including blackout and recoloring. The validator also accepts v1 bundles.
